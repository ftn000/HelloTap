# 🎨 Промо-материалы и графика для Яндекс Игр

Все графические ассеты подготовлены и нарезаны в соответствии с официальными техническими требованиями [Консоли разработчика Яндекс Игр](https://yandex.ru/dev/games/console/).

---

## 📁 Содержимое папки `promo/`

| Файл | Разрешение | Соотношение | Назначение в Консоли Яндекс Игр |
|---|---|---|---|
| **`icon_512x512.png`** | 512 × 512 px | 1:1 | **Иконка игры** (вкладка «Общие сведения» -> «Иконка») |
| **`icon_1024x1024.png`** | 1024 × 1024 px | 1:1 | Мастер-арт иконки высокого разрешения |

| **`banner_1920x1080.png`** | 1920 × 1080 px | 16:9 | **Промо-баннер** для рекомендаций и витрин («Баннер») |
| **`banner_1280x720.png`** | 1280 × 720 px | 16:9 | Стандартный горизонтальный баннер |

---

## 📌 Инструкция по загрузке в Консоль Яндекс Игр:

1. **Иконка игры:**
   * Откройте Консоль разработчика -> черновик игры -> вкладка **«Общие сведения»**.
   * В блоке «Иконка» нажмите «Загрузить» и выберите [`promo/icon_512x512.png`](icon_512x512.png).
   * *Примечание:* Углы иконки скруглять не нужно, Яндекс скруглит их автоматически.

2. **Обложка игры (Cover):**
   * В блоке «Обложка» загрузите [`promo/cover_800x600.png`](cover_800x600.png).

3. **Промо-баннер (16:9):**
   * В блоке «Промо-материалы» / «Баннер» загрузите [`promo/banner_1920x1080.png`](banner_1920x1080.png).

4. **Фавиконка и иконка для браузера:**
   * Уже интегрированы в папку `public/` проекта: [`public/icon.png`](../public/icon.png) и [`public/favicon.png`](../public/favicon.png).
